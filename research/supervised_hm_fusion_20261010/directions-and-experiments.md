# 选题、反证与决定性实验

状态：研究建议，不是已运行的实验结果。检索截止 2026-10-10。所有阈值、资源估算与停止条件为本次提出的工作决策，不能引用为领域标准。

## 1. 推荐主线：校准偏差下的受控监督融合

### 研究问题

给定由真传感器算子产生的 LR-HSI 与 HR-MSI，模型只能获得带误差的算子信息。如何利用监督数据学习修正，同时减少错误 SRF/PSF 驱动的谱误差放大？

第一阶段聚焦 SRF；输入已配准，HSI 31 波段、MSI 3 波段、尺度 ×8 固定。第二阶段再扩展 MSI blur 与 PSF。不在第一轮声称任意波段、任意尺度、完全盲响应或非刚性配准。

观测模型可写为：

\[
Y=D_H(X)+n_H,\qquad M=B_M(RX)+n_M.
\]

其中 \(D_H\) 包含 HSI PSF、采样、边界与相位，\(B_M\) 是 MSI 空间模糊。需要区分真值算子 \(\phi^\star\)、可获得估计 \(\widehat\phi\) 和对估计误差的描述 \(q(\phi\mid\widehat\phi)\) 或有界集合 \(\mathcal U(\widehat\phi)\)。

**实验生成观测用真算子，网络输入用估计算子。** 如果训练和测试都用同一个错误 R 去生成 MSI，那么测到的是另一个传感器的分布变化，并不是“校准信息错误”。

### 为什么值得验证

BHSR 已纳入 MSI blur；NUD/PAF 已纳入非均匀退化；SRLF 已按重投影错误选点；VPG 已利用不确定性生成先验。它们构成强前作。本路线希望额外回答“算子信息错了以后，修正行为和重建误差如何变化”，需要完整论文与实验对照才能确认研究距离。

2026-10-11 精读补充：SRLF 已比较可学习空间与光谱退化代理，不能把“学习未知响应”本身视为新贡献。最小比较集合增加 SRLF 固定先验版本与代理版本。作者核心实现使用通道注意力；计算节省需要测量实际排序、取点、回填和整网耗时，不能用空间注意力的点数平方复杂度解释。

本次还没有取得上述所有最新 TIP 全文，因此不把“它们没有处理此问题”写成已证事实。文献矩阵的 C 级记录必须在正式投稿前补全文，若已有等价方法则重新调整。

### 最小机制假设

先建立 HSI-only 参考重建 \(X_H=f_H(Y)\)，另一路提出受 MSI 引导的修正 \(\Delta=f_\Delta(Y,M,\widehat\phi)\)。输出：

\[
\widehat X=X_H+\mathcal C(Y,M,\widehat\phi,\text{误差描述},\Delta).
\]

\(\mathcal C\) 的目标是控制具体空间—光谱修正，不能仅用 64 个潜通道的 attention 充当物理可信度。

一个可检验的原型是：在物理谱基与空间模式中估计观测支持，再由监督目标训练允许的修正幅度。把展平图像上的联合观测算子记为 \(A_\phi\)，模式矩阵记为 \(U\)，则：

\[
G_\phi=U^\top A_\phi^\top\Sigma^{-1}A_\phi U.
\]

噪声协方差 \(\Sigma\) 与模式归一化必须固定口径。对模式 \(u_j\)，可考虑其在校准误差集合中的最小支持
\(\min_{\phi\in\mathcal U}u_j^\top A_\phi^\top\Sigma^{-1}A_\phi u_j\)。
实际使用局部或频域近似时，要说明近似范围；不能把局部量写成整幅图像可辨识性的证明。

**这还不是新算法。** Gram 矩阵、ridge 收缩、\(G(G+\tau I)^{-1}\)、鲁棒优化和门控都是已有工具。可能的贡献只能来自：真实可解释的误差模型、修正与谱风险之间的新机制、可验证的误差结论，以及强比较中不可被简化基线解释的收益。

### 最强反对意见

1. 它是不是普通 gate 加了物理名称？同参数 gate、只用重投影误差的 gate、普通 ridge 和算子条件 CNN 必须对照。
2. 好处是不是来自更多随机退化训练？全部方法共享相同训练退化分布与样本。
3. 是否只在错误 R 设置赢，干净设置明显掉分？绘制干净精度与错误响应鲁棒性的折中曲线。
4. 提供校准误差范围是否现实？分开报告知道误差范围、仅知道点估计、无任何校准信息三个条件；不能把 oracle 集合当部署条件。
5. 硬收缩是否抹掉由训练先验恢复的正确纹理？弱观测模式仍可由先验推断，但需报告条件性风险，而不是强制全零。
6. 是否在真实传感器上有意义？需有独立响应曲线或可信的估计误差依据，仅合成 Gaussian SRF 不足。

## 2. 辅助诊断：MSI 到底改善了什么

### 可证伪问题

MSI 的强边缘区域是否总是对应 HSI 各波段的真实收益？负收益能否从推理可得观测与传感器信息预测？控制它是否优于直接端到端重建？

最近邻：HSC-Sampling/MRC 的异谱结构补偿；SRLF 的错误位置重学习；UAFL 的相似度/调制；VPG 的不确定性先验；PAN 邻居 UMNet；2026-09 的未确认顶会预印本也已经有 HSI-preserving 分支和置信融合。**“双分支 + gate”本身不新。**

### 监督目标与诊断 oracle

以固定空间区域和物理谱模式的平方误差定义相对收益：

\[
b=\|X-X_H\|^2-\|X-(X_H+\Delta)\|^2.
\]

\(b>0\) 表示该候选修正有益，\(b<0\) 表示有害。对固定向量修正 \(\Delta\)，在同一完整平方损失下的最佳标量混合为：

\[
g^\star=\mathrm{clip}_{[0,1]}
\frac{\langle X-X_H,\Delta\rangle}{\|\Delta\|^2+\epsilon}.
\]

该公式是最小二乘投影的简单结果，用于诊断上限；它不是新颖性主张。若使用重叠区域、多种非正交修正、SAM 或 L1，则不能把这一闭式解直接称作全局最优。

训练真值可用于生成收益标签；推理不能使用真值。避免教师在训练样本上过拟合导致收益标签失真：教师采用按 scene 的 out-of-fold 预测，或使用单独教师训练集与标签生成集。验证/测试 GT 仅评价，不参与调节阈值。联合训练必须说明教师/标签何时更新。

不要只和 bicubic 比较，它会把 HSI-only 模型能力不足误认为 MSI 的收益；需要训练预算与容量合理的 HSI-only 网络。

### 两种决定性的反例

**测量不可辨识反例。** 对 band-independent 的空间退化，选取 \(Ru=0\) 的谱向量和 \(D_Hq=0\) 的空间模式，构造 \(\delta X=uq^\top\)。则
\(R\delta X=0\) 且 \(D_H\delta X=0\)。在幅度足够小、图像范围仍合法时，\(X\) 与 \(X+\delta X\) 给出相同观测；算法不能从观测唯一判定哪一个是真值。

这是线性观测的基本不可辨识性，不是我们的新定理。它说明“重投影误差小”“MSI 有边缘”都不能单独保证窄谱带 HR 细节正确。用它检验模型对先验歧义的行为，不要求模型解决信息论上不可完成的任务。

**错误参考反例。** 只改变 MSI 的空间错位、局部污染或输入给模型的 R，保持目标和 LR-HSI 不变。若模型接受了错误高频，会产生可测谱误差。但第一轮仅选择一种干扰，以免把几何问题和谱响应问题混在一起。

### 是否值得独立成文

只有当负收益群体稳定、可预测，且收益控制超过端到端 gate、SRLF、HSC 或强容量匹配基线时，才考虑独立方向。若只是更换损失或放大 CNN 容量造成小幅平均提升，它更适合作为主线的分析部分。

## 3. 第二路线：响应曲线形状条件化的跨传感器监督融合

### 研究问题

同样的中心波长与 FWHM 是否足够描述 MSI 提供的信息？如果两条 SRF 在中心与宽度上近似相同，但具有不同肩峰、侧瓣或带外泄漏，网络是否需要完整响应曲线才能重建可靠的 HR-HSI？

不同波段数量、wavelength embedding 和通道 mask 已有 DSES、OneHSI、CARL、LESSViT 等前作。连续辐射场与 SRF 积分已有 PINO；频域隐式融合已有 FeINFN。因此本路线应聚焦**真实响应形状与误差对重建的影响**，不能只做波长坐标编码。

### 可检验原型

用共享响应编码器处理 HSI 与 MSI 的响应曲线，以及可获得的 PSF/尺度信息，输出物理条件表示。用连续谱或固定谱网格重建，再通过目标 HSI 的响应积分产生输出：

\[
z_b(x,y)=\int L(x,y,\lambda)\,r_b(\lambda)\,d\lambda.
\]

目标必须是传感器测量对应的带积分，而不只是把 band center 上的点值当真值。离散积分需要明确波长网格、带宽、单位与归一化。

第一阶段仍可固定 31 个输出波段，只改变 MSI R 的形状；这样能辨别收益是否来自完整响应。真正可变输出谱网格、跨波长范围与多设备迁移放在后续。

### 决定性比较

| 条件 | 用途 |
|---|---|
| 固定通道 CNN，不提供任何 R | 传统参考 |
| 仅 channel count + band center | 低成本元信息参考 |
| band center + FWHM | 更强参数化参考 |
| 完整离散 SRF 曲线 | 检验形状信息的增益 |
| 完整但错误 SRF | 检验模型是否脆弱依赖元信息 |
| 整个真实 sensor family 留出 | 检验跨设备泛化，而非随机波段插值 |
| 同 shape 不同中心、同中心不同 shape | 分解坐标与形状因素 |

支持此方向需要实测或正式公开的响应曲线。没有曲线时可以做合成预实验，但结论不能提升为真实设备泛化。HSI 本身的响应也非理想 delta；由同一个 HSI 数据 cube 模拟多个 MSI 的实验，会继承原 HSI 的光谱带宽与标定局限。

风险较高：响应条件输入可能比没有元信息更差；不同设备的 radiometry、噪声和场景分布仍会混淆结果；连续谱解不因增加网络就获得唯一性。现有 baseline 只适合固定网格原型，后续需新接口和架构。

## 4. 分阶段实验与停止条件

### E0：先修协议并取得可信基线

固定 scene 名单与 train/val/test；统一 PSNR/SAM；保存真/估计退化算子、数据归一化和采样相位。保留原论文口径作为独立结果。

验收：同输入退化可复现；指标对 identity、固定误差、零范数谱的行为明确；验证集选模；最终测试不参与搜索。

### E1：建立有无 MSI 的收益图谱

训练 HSI-only、原双输入 CNN、容量匹配的增强双输入 CNN。以 scene 和波段/谱模式统计 MSI 的相对收益，按边缘强度、响应覆盖和噪声分组。分组定义在验证集冻结，不根据测试结果寻找“最好看”的子群。

停止条件：负收益只在明显故障样本发生，或者经更强 HSI-only/双输入训练后消失，且无法在独立数据集复现。此时不要为 gate 方向投入大型网络。

### E2：分离“新传感器”和“错误校准”

分别建立：

- 真 R 改变、提供正确 R：跨传感器条件变化。
- 真 R 固定、提供 \(\widehat R\) 改变：元信息校准偏差。
- 真 R 与估计都改变：部署复合变化，后做。

扰动幅度用 nm 偏移、相对带宽变化、泄漏能量等可解释单位，并让零扰动回到干净条件。每次重新归一化响应时记录是否改变辐射增益，不能将 gain error 意外消除。

最少比较：算子条件 CNN、随机退化训练 CNN、普通 gate、重投影 gate、ridge/支持收缩、拟议控制方法。外部方法包含 SRLF、HSC、BHSR；若评估扩散，则 EMR-Diff 与训练数据/算力成本一起报告。

另加入困难区域加权损失的廉价强对照。CVPR 2026 的 [DANet/MixShuffle/HAL](https://openaccess.thecvf.com/content/CVPR2026/html/Wen_Regulating_Rather_than_Constraining_Adaptive_Guidance_for_Complex_Spectral_Reconstruction_CVPR_2026_paper.html) 已有样本/通道/像素层梯度重分配；不能把“关注混合谱边界”本身称作新贡献。它是 PAN/MS 邻近任务，本次仅核验正式摘要；若迁移其数据混合，需同步处理响应关系，不可任意 shuffle 物理波段后仍沿用原 R。

停止条件：优势可由同分布退化增强或普通 gate 完全解释；对合理估计误差比增强 CNN 更脆弱；干净场景损失超过预先接受范围；结论只能在单个 CAVE split 成立。

### E3：扩展与外部证据

在 E2 有稳定结果后，再加 MSI blur/PSF、固定传感器家族留出、真实配对测量。未配准则单列 UAFL/SSC/IR&ArF，不将其加入主线后宣称算法一次解决所有真实退化。

建议至少 3 个独立训练种子作为第一轮稳定性检查；正式研究根据方差与预算调整。报告逐 scene 配对区间，以及典型和失败场景。可预先把“若改善小于种子波动，则不继续”写为决策规则，避免追逐 0.01 dB。

## 5. 论文应该围绕什么组织

一个可信的叙事是：常规监督融合依赖给定退化 → 实际校准偏差会改变修正的测量支持 → 对照实验区分响应改变、元信息错误与普通域改变 → 可解释地控制修正 → 在明确边界内减少谱风险。

主张必须与证据对应：

| 拟议主张 | 所需证据 | 不能替代的东西 |
|---|---|---|
| 控制错误 SRF 导致的额外误差 | 固定真实观测、只扰动元信息，配对误差曲线 | 只随机生成更多 Gaussian SRF |
| 比普通可信度 gate 更有用 | 同参数、同数据、同损失预算强对照 | 门控热力图 |
| 物理谱模式分析有意义 | 真实 band/response 空间与模式 ablation | 64 维潜通道权重解释 |
| 跨真实设备可迁移 | 设备家族留出与响应来源 | 同一 cube 的随机波段切片 |
| 部分细节不受观测唯一支持 | 不可辨识反例与错误/先验行为分析 | “data consistency 小，所以正确” |
| 推理不需要 GT | 输入审计、标签生命周期、保存配置 | 训练可用真值这一常识 |

期刊匹配只是研究定位建议：若贡献围绕退化模型、可解释重建机制与充分实验证据，TIP/IJCV 较自然；若希望面向 TPAMI/CVPR/NeurIPS，需要更广泛的科学问题、机制或理论与跨系统实证。任何当前构想都不构成录用保证。
