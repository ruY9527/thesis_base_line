# SDP-Net: A Spatially Guided Dual-Path Network for Hyperspectral and Multispectral Image Fusion

Official implementation of:

**A Spatially Guided Dual-Path Network for Hyperspectral and Multispectral Image Fusion**

This repository provides the PyTorch implementation of SDP-Net for hyperspectral and multispectral image fusion (HMIF). SDP-Net is designed to recover a high-resolution hyperspectral image (HR-HSI) from a low-resolution hyperspectral image (LR-HSI) and a high-resolution multispectral image (HR-MSI).
